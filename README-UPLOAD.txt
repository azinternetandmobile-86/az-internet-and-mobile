UPLOAD TO GITHUB PAGES
1. Open https://github.com/azinternetandmobile-86/az-internet-and-mobile
2. Open the main branch and upload all files from this folder into the repository root.
3. Keep existing image files az-logo.png, shop-front.png and youtube-banner.jpg in the root. Do not delete them.
4. Commit changes to main. GitHub Pages will publish the update after its build completes.

ADMIN FIRST USE
Open /admin.html. Create an admin password of at least 10 characters. Remember it.

IMPORTANT LIMITATIONS
This version is a static GitHub Pages website. The booking form saves a copy only in the visitor's browser and offers a WhatsApp handoff; it does NOT send bookings to a central database. Admin products and requests are stored only in the same browser/device. The password is a local browser gate, NOT production-grade security. Do not store sensitive customer documents, OTPs, bank details, passwords or payment credentials. For true multi-device management, secure login, central booking storage and live inventory, connect a backend such as Firebase/Supabase with server-side rules.
